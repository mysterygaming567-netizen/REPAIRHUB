# RepairHub

## Project Description

RepairHub is a web-based device repair platform that connects customers with verified local repair shops and technicians. Customers can find repair services, submit repair requests, describe device issues, track repair progress, and communicate with shops. Repair shops can manage repair requests and update their service progress, while administrators can manage the platform.

## Main Features

- Customer, shop owner, and administrator account roles
- Email and password registration and login
- Verified repair shop discovery
- Repair request submission and tracking
- Shop dashboard and repair status updates
- Firebase-backed user and repair data

## Running the Project

1. Open the project folder in Visual Studio Code.
2. Serve the project with a local web server.
3. Open the server URL and navigate to `index/index.html`.

The Firebase configuration is stored in `login/firebase-config.js`.
